# Python Game: Falling Dodge

A simple `tkinter` dodge game where you move the green square left and right to avoid falling red blocks.

## How to play

- Run the game with `python game.py`
- Use `Left Arrow` / `A` to move left
- Use `Right Arrow` / `D` to move right
- Press `Enter` to start or restart

## Requirements

- Python 3.x
- No external packages required
